这是 **Ruii’s Margins** 的第一篇文章。先搭好一个安静、清晰的写作空间，再慢慢积累内容。

## 这里会记录什么

主要围绕三个方向展开：

- **软件工程**：写代码、做项目，以及工程实践中的问题和选择。
- **AI**：阅读、实验与实现过程中的学习笔记。
- **持续学习**：把零散的知识整理成自己能够解释清楚的文字。

文章不必一开始就完整。能够明确问题、保留依据，并在发现错误后修正，就是一个好的起点。

## 这一版博客

页面采用单栏布局，把注意力留给正文。首页展示文章和摘要，归档按时间整理内容，标签用于按主题浏览，搜索支持查找文章标题与正文。

右上角可以切换深色和浅色模式。文章页有目录、代码复制按钮和上一篇 / 下一篇链接。

## 从一份 Markdown 到一篇文章

文章以 Markdown 文件保存，连同图片一起放在 GitHub 仓库中。

```text
写作 → 提交到 GitHub → 自动构建 → 发布到博客
```

每一次修改都有记录，也可以在需要时回到旧版本。日后可以在这套流程上增加浏览器编辑入口。

## 慢慢来，持续写

先完成第一篇，再完成下一篇。
